# Sidebar Feature

Handles conversation navigation and history management.

## Components
- `Sidebar`: Main container for chat list and search.
- `ConversationItem`: Individual entry in the history list.
- `SearchInput`: Filters the conversation list.

## Hooks
- `useSidebarGrouping`: Logic for categorizing chats into time-based groups (Today, Yesterday, etc.).
- `useSidebarActions`: Handles sidebar-specific UI interactions.
